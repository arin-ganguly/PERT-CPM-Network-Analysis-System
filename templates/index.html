Scheduling Models

PERT vs CPM

PERT is ideal when task durations are uncertain. It uses optimistic, most likely, and pessimistic estimates to calculate expected time.

CPM is used when activity durations are fixed and known. It focuses on schedule timing, float, and project control.

In both methods, the critical path is the sequence of tasks that directly determines the total project duration.

Critical Path

Critical Path Visualization

The critical path is the longest path through the project network.

Tasks on this path have no delay allowance, so any slip directly impacts delivery.

This path ultimately determines the total project duration and helps teams focus on the work that matters most.
